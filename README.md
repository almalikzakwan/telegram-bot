# Telegram-bot
Telegram-bot build for learning and sharing. Main purpose of this project is to maintain chat between user and bot.

## Tools
- linux
- python

## Installation
```bash
python3 -m venv .venv # optional if you want to use virtual environment.
source .venv/bin/active # optional if you execute first line
pip install -r requirements.txt # to install project requirements.
python3 main.py
```

Create .env file and put your token as example
```txt
token = "bot#token"
```
